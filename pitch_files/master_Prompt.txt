PROJECT: ANIMAL HEALTH BRIDGE
═══════════════════════════════════════════════════════════════════════

An offline-first, multilingual Android app that turns an animal owner's 
spoken symptoms into a structured veterinary case — entirely on the phone.

Built for iQOO City Battles 2026 · HealthTech Track
Team: Sohail Squad

CORE PRINCIPLE:
The owner speaks freely in their own language. The system understands, 
structures, and prepares a case. The vet reviews, asks follow-up questions 
if needed, and decides treatment. The app never diagnoses or chooses 
treatment. The vet is the sole prescriber.

═══════════════════════════════════════════════════════════════════════
WHAT THE APP DOES (Core Loop)
═══════════════════════════════════════════════════════════════════════

1.  IDENTIFY   — Scan NFC/QR tag, open persistent health profile
2.  INGEST     — Owner speaks symptoms freely in their language
3.  TRANSLATE  — On-device translation to English
4.  REASON     — On-device LLM structures the case into JSON
5.  TRIAGE     — Rules engine assigns urgency
6.  REVIEW     — Case card displayed with all extracted fields
7.  VET        — Vet reviews case
8.  QUERY      — Vet can ask follow-up questions with evidence requests
9.  RESPOND    — Owner responds with text, photos, or video
10. PRESCRIBE  — App generates vet-approved prescription document
11. RECORD     — All data saved to longitudinal health record
12. REMIND     — Dose reminders + withdrawal period tracker

     "values": ["low"], "action": "SEE_VET_TODAY"},
    {"id": "R6", "field": "default", "action": "MONITOR"}
  ]
}

Evaluator logic:
- Walk rules in order, first match wins
- EMERGENCY overrides all lower urgency
- If confidence is "low", escalate to SEE_VET_TODAY
- Log every decision with matched rule ID + extracted fields

SENSOR INTEGRATION DETAILS
═══════════════════════════════════════════════════════════════════════

Gyroscope (TYPE_GYROSCOPE):
  Purpose: Detect phone shake during gait video capture
  Logic:   If angular velocity > 0.5 rad/s sustained, show "Hold steady"
  Evidence: Nature Scientific Reports (2026) — gyroscope-based methods
            more precise than accelerometer for stride detection

Accelerometer (TYPE_ACCELEROMETER):
  Purpose: Complement gyroscope for steadiness score
  Logic:   Combine with gyroscope into single steadiness value

Light Sensor (TYPE_LIGHT):
  Purpose: Warn "Too dark" before photo capture
  Logic:   If lux < 50, show warning

Proximity Sensor (TYPE_PROXIMITY):
  Purpose: Auto-pause if phone is covered
  Logic:   If proximity indicates near, pause recording

All sensor checks have a fallback: if sensor unavailable, skip and proceed.
